BioinfoFlow

Agentic bioinformatics workflow platform. Solo project, MIT license. Dec 2025 to present, built as a side project alongside my BGI role.

bioinfoflow.com · GitHub · Python, TypeScript, FastAPI, Next.js, Docker

Users describe an analysis in plain language. The agent reads the project files and prepares inputs and parameters. After the user approves, it submits a Nextflow or WDL run, follows the logs, and explains the results. Data and compute stay on the user's own machine or server.

  • Wrote the agent runtime. Sessions are durable and history is append-only. The model uses a few general tools (read, bash, edit, write, ask_user) and drives the product through its CLI.
  • The runtime handles context compression, retries, cancellation, and checkpoint recovery. It has three permission modes: ask before changes, ask before dangerous actions, and full access.
  • The backend uses FastAPI and a Typer CLI. One engine interface covers Nextflow and MiniWDL.
  • A persistent scheduler handles queueing, resource checks, retries, timeouts, and cleanup. Run state streams to the UI over SSE and WebSocket.
  • The Next.js UI has pages for workspaces, the dashboard, the agent, workflows, runs (logs, DAGs, outputs), container images, the scheduler, and settings.
  • SSH remote hosts: save profiles, test hosts, open in-browser terminals, and hand a selected host to the agent. Remote agent commands run in a Bubblewrap sandbox.
  • Ships as Docker Compose with a one-line installer. Released v0.1.0 (Jul 2026) and v0.2.0 (Jul 2026) on GitHub.
  • The repository includes an nf-core/rnaseq demo, WDL fixtures, and NVIDIA Parabricks WGS examples that run on a single consumer GPU such as an RTX 4080 SUPER.

Trove

Workspace for starred GitHub repositories. MIT license. Nov 2026.

GitHub · TypeScript, Next.js, React, SQLite

Trove organizes the repositories you have starred on GitHub, on your own machine. Data lives in a local SQLite file.

  • Organize repositories with tags and collections. With a model configured, AI can categorize them for you.
  • A repository graph links repositories that share a tag, a collection, or a topic, drawn with a force-directed layout.
  • Radar suggests new repositories from sources such as GitHub search and Hacker News.
  • A Releases inbox collects new versions of the repositories you use and flags likely breaking changes.
  • AI writes a health report for a repository.
  • A built-in MCP server lets coding assistants call Trove with a token. A CLI mints and revokes tokens.
  • Model providers: OpenRouter, OpenAI, Anthropic, DeepSeek, local Ollama, and any OpenAI-compatible server. The Ollama URL must be a loopback address.
  • English and Chinese interface. Runs with Docker Compose.

Loadout

macOS manager for AI agent skills. Solo project, MIT license. Oct 2026.

GitHub · Rust, Tauri 2, React, SQLite

  • Released v0.2.1 as a universal build that runs natively on Apple silicon and Intel.
  • Scans ~/.agents and the skill folders of Claude Code, Codex, Cursor, Gemini, and OpenCode, and merges them into one deduplicated list. A symlinked skill shows once with several installs.
  • Installs, updates, and deletes skills in the app. An update keeps the previous folder as a backup. Deleted files go to the Trash.
  • The Rust side scans folders, watches them with a debounced file watcher, and parses agent session logs. Usage is indexed into SQLite with only the skill, the agent, and the day. Prompts and replies are never copied.
  • Shows a usage heatmap. The UI is in English and Chinese, with light, dark, and system appearance.
  • Asks for no Full Disk Access, Automation, Accessibility, or Screen Recording permission.

Folio

Local Markdown library for the X Articles you saved. Apache-2.0 license, macOS Apple Silicon preview. Nov 2026.

GitHub · TypeScript, Electron, React

  • Imports X Articles from your bookmarks through a Chrome extension. Requests run in the background and do not open or refresh X tabs.
  • Saves articles as local Markdown with local images. You can open the same folder in Obsidian or Cursor.
  • Browse by topic and reading status, rate articles, and add annotations.
  • Optionally organizes selected articles into topic notes and cards with your own model API key. You review the output before it is saved. The key is encrypted with the system's secure storage.
  • English and Chinese UI, with light, dark, and system appearance.
